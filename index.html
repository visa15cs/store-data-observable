A SMALL PATTERN WITH BIG USES
Listen close.
Stay in sync.
Sometimes one value changes and several parts of an app need to know. The store keeps data in one place, then tells the right listeners when something changes.
Subscribe to one key when you need a focused update. Add a global listener when you want to observe everything. Either way, listeners stay registered—even after a key is unset.
IN PRACTICE
Think profile state, a cart total, or a setting that several components rely on. One update; every subscriber gets the memo.

FOUR METHODS, THAT’S IT
Small surface area.
Clear behavior.
Built around Map for stored values and Set for listeners. Multiple subscribers can watch the same key.
＋set(key, value)
Store a value, then notify key-specific and global listeners with the old and new values.
⌕get(key)
Read the current value. A missing or unset key returns undefined.
−unset(key)
Remove a value without removing its listeners. The key can be set again later.
◎onChange(...)
Subscribe to a specific key or pass a callback alone to observe every key.
